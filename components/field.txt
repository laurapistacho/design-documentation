11:Tc8f,# Field (TextField, TextArea, Select, Autocomplete)

Form input components share a unified token system and visual structure. This doc covers the shared anatomy; each variant has specific behavior.

## Overview

### When to use
- Collecting user input (text, numbers, dates)
- Selection from a list of options
- Search/filter within datasets
- Multi-value input (tags, recipients)

## Shared Anatomy

1. **Label** (optional) — above the input, describes the expected value
2. **Container** — border with state-driven color
3. **Input area** — text, placeholder, or selected values
4. **Icon left** (optional) — input type indicator
5. **Icon right** (optional) — action (clear, expand, calendar)
6. **Helper text** (optional) — below input, guidance or validation feedback

## Sizes

| Size | Height | Font | Usage |
|------|--------|------|-------|
| Large | 48px | body1 (16px) | Standalone forms, modal inputs |
| Small | 36px | body2 (14px) | Table inline edits, compact forms, filter bars |

## Styles

| Style | Usage |
|-------|-------|
| Outlined | Default — visible border container |
| Ghost | Inline editing — no border until focus |

## States (Unified Field Tokens)

All form inputs use the same state-driven colors:

| State | Border | Text | Icon |
|-------|--------|------|------|
| Default | #777777 | #111111 | #636363 |
| Hover | #282828 | #111111 | #636363 |
| Focused | #014cb7 (RPP70) | #111111 | #014cb7 |
| Filled | #777777 | #111111 | #636363 |
| Error | #D3000C | #111111 | #D3000C |
| Warning | #C28A29 | #111111 | #C28A29 |
| Disabled | #A4A4A4 | #BBBBBB | #BBBBBB |

**Focus glow:** `0 0 8px 3px rgba(42, 82, 114, 0.20)` — applied on focus for all field types.

## Variants

### TextField
Single-line text input. Right icon toggles visibility (password) or clears value.

### TextArea
Multi-line text input. Resizable vertically. Shows character count if configured.

### Select / Autocomplete
Dropdown with search. Can be single-select or multi-select (chips in input).
- **Expanded:** shows dropdown list with search field
- **Loading:** spinner replaces chevron
- **Multi-value:** selected items appear as Chips inside the input

### Searcher
Standalone search field. Keyboard shortcut indicator ("/"). Clear on Escape.

## Do / Don't

- Do: always include a Label when the field is part of a form
- Don't: use placeholder text as a substitute for labels
- Do: provide Helper text for validation feedback
- Don't: mix Large and Small fields in the same form
- Do: use Ghost style only for inline/table editing contexts
- Don't: disable fields without explaining why (use helper text)

## Spacing

| Property | Value |
|----------|-------|
| Label to input gap | 4px (xs) |
| Input to helper gap | 4px (xs) |
| Internal padding (Large) | 12px vertical, 16px horizontal |
| Internal padding (Small) | 8px vertical, 12px horizontal |
| Icon to text gap | 8px (s) |
