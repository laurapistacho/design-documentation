11:Tba5,# Empty States

Empty states appear when there's no content to display. They guide users toward their next action instead of showing a blank screen.

## Types

### No Data (First Use)

The user hasn't created any content yet. The empty state explains what goes here and how to get started.

**Structure:** Illustration + headline + description + primary CTA

```
        [Illustration]
    No surveys created yet
  Create your first survey to start
  collecting guest feedback.

       [Create Survey]
```

### No Results (After Filter/Search)

Data exists but the current filters/search return nothing.

**Structure:** Icon + message + clear filters CTA

```
       [Search icon]
    No results match your filters
  Try adjusting your search terms
  or clearing filters.

       [Clear Filters]
```

### Error State

Data failed to load due to a network or server error.

**Structure:** Error icon + message + retry CTA

```
       [Error icon]
    Unable to load data
  Something went wrong. Please try
  again or contact support.

          [Retry]
```

## Sizing Contexts

| Context | Size | Illustration | CTA |
|---------|------|--------------|-----|
| Full Page | Large | Big pictogram (200px+) | Primary Large button |
| Content Area | Medium | Medium pictogram (120px) | Primary Small button |
| Tile / Card | Small | Small icon (48px) or none | Ghost or Link button |

## Anatomy (Perkins Component)

The Figma component "Perkins" (`1535:1222`) handles empty states with:
1. **Pictogram** — swappable illustration slot
2. **Message** — headline + description (centered)
3. **Actions** — none, link, or button

## Visual Rules

- Center horizontally and vertically within the container
- Text: headline in subtitle1 (16px/500), description in body2 (14px/400, secondary color)
- Max text width: 320px (prevents unreadable long lines)
- Vertical spacing: 16px between pictogram and text, 24px between text and CTA

## Content Rules

- Headline: state what's missing, not what went wrong
  - "No reviews this week" (not "Error: no data")
- Description: explain why and what to do next
  - "Reviews will appear here once guests complete their stay surveys."
- CTA: specific action verb
  - "Create survey" (not "Get started" or "Learn more")

## Do / Don't

- Do: provide a clear next action (CTA button or link)
- Don't: show an empty table/list with no explanation
- Do: differentiate "no data ever" from "no results for this filter"
- Don't: use the same message for first-use and no-results
- Do: keep the surrounding chrome visible (header, sidebar, breadcrumbs)
- Don't: hide page structure when showing an empty state
- Do: use the Perkins component for consistency
- Don't: write custom empty state layouts per page
