11:T122c,# Navigation

The ReviewPro admin shell uses a two-level navigation: a persistent TopNav bar and a collapsible SideNav rail with expandable panels.

## Structure

```
+------------------------------------------------------------------+
| TopNav (56px, fixed, z-index: 1000)                              |
| [Logo] [Establishment ▾] [Date Range ▾]    [Notif] [Help] [Av]  |
+--------+---------------------------------------------------------+
| Side   | Content Area                                            |
| Nav    |                                                         |
| 56px   | Page Header                                             |
| icon   | +-------------------------------------------------+     |
| rail   | | Breadcrumbs                                     |     |
|        | | Title                        [Actions]         |     |
| hover  | | [Filter bar]                                    |     |
| expands| +-------------------------------------------------+     |
| to     |                                                         |
| 248px  | Page Content                                            |
| panel  |                                                         |
+--------+---------------------------------------------------------+
```

## TopNav (56px)

Fixed at top, spans full width. Contains:

| Position | Element | Behavior |
|----------|---------|----------|
| Left | Logo (ReviewPro/Shiji) | Link to dashboard |
| Left-center | Establishment selector | Dropdown, shows current property |
| Center | Date range selector | Dropdown, shows selected period |
| Right | Notifications | Badge with count, opens panel |
| Right | Help | Opens help center |
| Right | Avatar | User menu dropdown |

**Variants:**
- Default (single property): establishment name + date
- Corporate (multi-property): corporate banner, different nav background (#172554)

**Background:** RPP-70 (#014cb7) for default, corporate navy (#172554) for chain view.

## SideNav

### Collapsed State (Icon Rail, 56px)

Vertical icon list. Each icon represents a section. Active section highlighted.
On hover: tooltip with section name.

### Expanded State (Panel, ~248px)

Slides out on hover or click. Shows:
- Section title with "New" chip (if applicable)
- Sub-navigation items as text links
- Dividers between groups

### Sections (12 total)

| Section | Icon | Contains |
|---------|------|----------|
| Dashboard | grid | Overview, My Page |
| Reviews | star | Review list, Response management |
| Surveys | clipboard | Survey results, Configuration |
| Semantic | brain | Semantic analysis, Topics |
| Cases | folder | Case management |
| Messaging | chat | Conversations, Channels |
| Guests | people | Guest profiles |
| Revenue Optimizer | trending | Rate optimization |
| Analytics | chart | Reports, Custom analytics |
| Manage | settings | Team, Properties, Integrations |
| Settings | gear | Account, Notifications, Permissions |
| Learning | book | Help resources, Academy |

### Mobile Behavior

Below `sm` breakpoint (768px):
- SideNav becomes a full-screen drawer overlay
- Opened via hamburger icon in TopNav
- Closes on navigation or outside tap

## Page Header

Sits at the top of the content area. Contains:

1. **Breadcrumbs** (optional) — shows path within the section
2. **Title row** — page name + action buttons (right-aligned)
3. **Filter bar** (optional) — toggle buttons, search, filter icon with badge

### Header Variants

| Type | Content |
|------|---------|
| Default | Title + actions |
| With breadcrumbs | Breadcrumbs above title |
| With tabs | Tab bar below title (replaces filter bar) |
| With filters | Filter bar with toggle groups + search |

## Responsive Behavior

| Breakpoint | Navigation |
|-----------|------------|
| >= lg (1440px) | Full layout, sidebar can stay expanded |
| md-lg (980-1440px) | Collapsed sidebar by default |
| sm-md (768-980px) | Collapsed sidebar, simplified header |
| < sm (768px) | No sidebar rail, drawer overlay, stacked header |

## Do / Don't

- Do: keep the TopNav consistent across all pages
- Don't: hide the TopNav on scroll
- Do: highlight the active SideNav section
- Don't: nest more than 2 levels in the sidebar panel
- Do: collapse the sidebar when content needs space (data tables, charts)
- Don't: put actions in the sidebar — it's for navigation only
