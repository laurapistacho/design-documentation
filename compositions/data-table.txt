11:T13ce,# Data Table

The primary pattern for displaying and interacting with lists of structured data across the ReviewPro platform.

## Structure

```
+----------------------------------------------------------+
| Toolbar (optional)                                       |
| [Search] [Filters ▾] [Toggle view] [Bulk actions]       |
+----------------------------------------------------------+
| Header Row (sticky)                                      |
| [☐] [Column A ↕] [Column B ↕] [Column C] [Actions]     |
+----------------------------------------------------------+
| Data Row (hover: actions appear)                         |
| [☐] [Content]    [Content]     [Content]  [...] [⋮]    |
+----------------------------------------------------------+
| Data Row                                                 |
+----------------------------------------------------------+
| Data Row                                                 |
+----------------------------------------------------------+
| Pagination Footer                                        |
| Rows per page: [25 ▾]              1-25 of 142  < >     |
+----------------------------------------------------------+
```

## Row Types

| Type | Usage |
|------|-------|
| Header | Column labels + sort indicators, sticky on scroll |
| Data (default) | Standard content row |
| Data (editable) | Inline-edit fields visible |
| Toolbar | Search + filters + bulk actions above table |
| Pagination | Page navigation below table |
| Bottom Actions | Action buttons below table (save, cancel) |
| Mobile | Card-like stacked layout for narrow viewports |

## Row Sizes

| Size | Row Height | Usage |
|------|-----------|-------|
| L | 56px | Default, comfortable reading |
| M | 48px | Compact, more rows visible |
| S | 40px | Dense, dashboards, monitoring |

## Cell Content Types

| Type | Elements |
|------|----------|
| Text + Chip | Primary text, optional secondary line, status chip |
| Icon Buttons | Action icons (edit, delete, more) |
| Checkbox/Radio | Selection cells |
| Switch | Toggle state |
| Field (inline) | Editable text/select within the row |
| Bar | Volume/progress indicator |

| Icons | Status/channel indicators |
| Drag | Drag handle for reordering |

## Interactions

### Sort
- Click header toggles: none > ascending > descending
- Active sort shows arrow indicator
- Only one column sorted at a time (default)

### Selection
- Checkbox in first column (header = select all)
- Selected rows get highlighted background
- Bulk action bar appears when selection > 0

### Actions on Hover
- Action buttons float in from the right on row hover
- Typically: edit, delete, more (3 max without overflow)
- Positioned above row content, white background gradient

### Pagination
- Rows per page selector (default: 25, options: 10/25/50/100)
- Page count label: "1-25 of 142"
- Navigation: first, prev, next, last

### Inline Edit
- Triggered by row click or edit action
- Row expands slightly, fields become active
- Save/Cancel appear (inline or in footer)
- Cell border changes to focused state

## Row States

| State | Appearance |
|-------|------------|
| Rest | No highlight |
| Hover | Light background (#F8F8F8 or neutral_05) |
| Selected | Blue tint background (#EBF2F8) |
| Disabled | Muted text, no interaction |
| Focused | Blue border outline (accessibility) |

## Do / Don't

- Do: make headers sticky on scroll for long tables
- Don't: use horizontal scroll unless absolutely necessary (prefer column priority)
- Do: provide a clear empty state when no data matches filters
- Don't: hide pagination when there's only one page (show it disabled)
- Do: use actions-on-hover for secondary actions
- Don't: put more than 3 visible actions per row (use a "more" menu)
- Do: align numeric data right, text left
- Don't: alternate row colors — use hover + divider lines instead

## Empty State

When a table has no data:
- Replace the table body with the Perkins/Placeholder component
- Show: icon + "No results found" message + clear filters CTA
- Keep the header row visible (user can still sort/filter)

## Responsive Strategy

| Breakpoint | Behavior |
|-----------|----------|
| >= md (980px) | Full table with all columns |
| sm-md (768-980px) | Hide low-priority columns, show "more" expand |
| < sm (768px) | Card-based layout, one card per row |
